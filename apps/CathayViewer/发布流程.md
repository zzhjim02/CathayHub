# 发布流程

1. 改版本号：`gui.py` 与 `viewer_core.py` 里的 `APP_VERSION`
2. 自检（本机均已跑通，无需 offscreen）：
   - `py -3 viewer_core.py --selftest`
   - `py -3 viewer_meta.py`
   - `py -3 gui.py --selftest2`      （Windows 默认走原生平台；offscreen 崩溃已修）
   - `py -3 开发\功能自检.py`         （63 项真平台·全功能核验）
3. 打包：双击 `打包EXE.bat`（或 `py -3 fab.py`）→ `dev_dist\CathayViewer.exe`
   （同时生成 `dist\Release\`：exe + 校验值.txt + 发行说明）
4. 组装发布包：`py -3 开发\make_release.py`
   → 生成 `..\CathayViewer 学术书库浏览与阅读 <版本>\` 与同名「（含源码）」zip。
   **自动排除** `*.db / *settings.json / dev_dist / dev_build / dist / __pycache__ / _dbg* / _probe*`
   ——索引库（可能几百 MB）绝不会被打进包
5. 上传：百度网盘（密码 2026）+ GitHub Release（附件用 ASCII 名）
6. 回填 README 下载表 + 校验值

## 坑

- **绝不把 `cathayviewer_index.db` 打进包**（可能几百 MB）：`make_release.py` 已自动排除，勿手动绕过
- `--name` 不要与源码包/目录同名
- PyQt6 用 PyInstaller 默认 hook 即可；PyMuPDF、ijson 会自带
- `.bat` 里不写中文（cmd 按 GBK 解析会乱）
- 自检/测试里 `QApplication` **必须用变量持引用**：
  `app = QApplication.instance() or QApplication(sys.argv)`；若只写 `QApplication(sys.argv)` 丢弃返回值，
  包装对象会被 GC → 构造 `MainWindow` 时 Windows fail-fast（0xC0000409，无 traceback）
