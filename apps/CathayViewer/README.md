## 🔗 Cathay 人文社科工具链

| 步骤 | 工具 | 功能 |
|:---:|---|---|
| ① | CathayIndex | 把本地文件夹建成可检索的「本地文件库」 |
| ② | CathayFinder | 综合性图书检索引擎：11 个渠道精准查书 |
| ③ | CathayPDG | 读秀/超星 PDG 批量转 PDF |
| ④ | CathayOCR | 扫描件 OCR，产出可搜索文字层 PDF |
| ⑤ | CathayShelf | 图书著录自动化整理 |
| ⑥ | **CathayViewer（本仓库）** | **书库浏览与阅读：文件名搜索、元数据、多版本、学术引用、阅读体验** |

> 🧭 CathayViewer 是 CathayReader 的升级版：把「本地书库」浏览、搜索、精读三件事做在一起。

## ✨ 功能

- **文件名索引**（不是全文索引）：扫指定书库目录建自己的索引库，增量刷新；**绝不改动源书库一个字节**
- **单窗口默认**：左侧「文件列表」+ 右侧「阅读器」，**分隔条可拖**、阅读器占约 3/4；**窗口大小/位置 + 分隔比例 + 是否拆窗都会记住**（默认 1200×820，不占满屏）；点「🗗 独立窗口」可把阅读器拆出去（关窗自动收回）　**（batch10）窗宽随意拉：PDF 会自动重新缩放，整页左右都看得见。**
- **列表 3 列**：序号 ｜ 文件名 ｜ 上级文件夹（只显示紧邻上一层；**单击文件名即打开**；命中关键词**黄底高亮**）
- **元数据解析**：从文件名取 书名 / 卷册 / 作者 / 出版社 / 年份 / SSID / 繁简标记（沿用 CathayShelf 规则）
- **多版本聚合**：同一本书的 `原本 PDF` / `_【繁转简】.txt` / `_PD6AIFOCR.pdf` 合成一条，下拉切换，原本排第一
- **一键复制学术引用**：`作者：《书名》，出版地：出版社，年份，第X页。`
- **阅读体验**：主题（浅色/深色/护眼）、字号 8–30、F11 全屏、**PDF 默认「适应页面」**、**顶部紧凑**（一行控件，详情默认隐藏、点「ⓘ」展开）、**PDF 连续纵向滚动阅读**（滚轮/触控板**像素级平滑滚动**，`↑`/`↓` 小步滚动，PgUp/PgDn 整页翻；页图懒渲染 + 缓存，同一页只渲染一次，不卡界面）、**缩放**（适应宽度 / 适应页面 / 100% + `Ctrl+滚轮`）、**可输入页码框 N / M**、**导航面板**（目录 + 缩略图 + 查找，打开 PDF/EPUB 默认展开、**目录单击即跳页**、自动高亮当前章节）、**文内查找**（Ctrl+F）、阅读位置记忆（Ctrl+B，重开自动跳回）
- **🗗 阅读器独立窗口**：一键把阅读区拆成独立窗口，最大化后几乎占满全屏看书（再点收回；关窗自动收回）
- **🖱 选中 PDF 里的字**：有文字层的 PDF 可直接鼠标拖选、**跨页连选**并复制（选完自动入剪贴板；右键「复制本页文字 / 全选本页」）
- **🔎 跨文件全文检索（在左侧列表上方）**：对**当前搜索结果**里的 **PDF 与对应 TXT** 逐页全文查找，**另开独立进程**跑，界面不卡；结果列表双击即跳到该页，可「全部复制」
- **检索去重（单文件 Ctrl+F 与跨文件共用一套）**：只在**同一目录**内、**只比对 PDF/TXT** ——
  · 同名 PDF 与 TXT（PDF 的 `_opt` 忽略、视为同名）：**命中数相同 → 只显示 PDF**；
  · 同名 PDF 与 TXT、**命中数不同 → 两条都显示，TXT 标「（TXT）」**；
  · 同一本书**不同 OCR 引擎**的 TXT（`_PD6AIFOCR`/`_PD6GJOCR`…）→ 都显示；
  · **原版 TXT 与对应繁/简 TXT** → 都显示（不互相顶掉）；无同名 PDF 的 TXT 照常显示。
  （命中数 = 关键词在该文件里的真实出现总次数；EPUB/MD/JSON 不参与配对）
- **被去重项默认隐藏**：单文件在「查找」页签底部、跨文件在结果窗底部，各有一个**「▸ 显示被去重的 N 项」小按钮**，点开可查看/复制（再点收起）。
- **📜 版权/授权信息**：选中文件时，从**文件名 + 上级目录名 + PDF 版权页（CIP）** 三处合并提取 授权 / 版权 / 出版发行 / ISBN / 版次 / 印次 / 出版年月，并标注每条来源
- **索引库位置自选**（可放移动硬盘/另一台机器），认盘用卷序列号，拔盘不崩
- **可选文件关联**：附 `关联.bat` / `取消关联.bat`（当前用户 HKCU，纯 ASCII），把 `.pdf/.epub/.txt/.md` 关联到 CathayViewer；**程序本体不碰注册表**，关联全靠你手动双击脚本
- **窗口自适应（batch10）**：PDF 缩放默认「适应页面」，窗口拉大/拉小会自动重排，**整页含左右边缘始终完整可见**（不会被导航栏挡住、也不留空）；文件列表**已去掉行号列**，文件名列自动铺满、**上级文件夹按内容显示全**；导航页签在窄窗口也不挤掉字；**版本下拉切换即真正打开该版本**；查找结果打不开时会明确提示（不再默默无反应）。

### 🆕 batch11 / batch12 新增

- **📷 截图本**：把当前 PDF 页面（或右键「▣ 框选截图」拖出的区域）一键存进**系统「文档」→ `Cathay文档记录\截图本\`**，保存时提示你输入页码；每张图在 `截图本.md` 里自动附**书名 / 页码 / 版本 / 文件**。
- **✂ 摘录本**：选中一段文字一键摘录，自动附**书名 · 卷册 · 页码 · 版本 · 出版社·年 · 文件名**，写到 **`文档\Cathay文档记录\摘录本\摘录本.md`**；摘录里若含纪年会**自动换算**（见下）。
- **⇄ PDF + TXT 对读**：打开 TXT 时若同目录有同名 PDF，**自动进入对读**；**PDF 在左、TXT 在右，中间是 PDF 导航页**，按页码标记**双向同步**翻页；进对读时 **PDF 停原页、TXT 同步到该页**；中间可直接切换 **TXT 版本**（不同 OCR / 繁简），并可一键 **只看 PDF / 只看 TXT**。
- **🕘 跨文件检索历史**：每次「跨文件全文检索」的结果**自动保存**，点「🕘 检索历史」随时调阅、双击重开该次结果、可删可清空。
- **⤒ 版权页更聪明**：打开版权页时**先查 PDF 目录（标签页/书签）里有没有「版权页 / 版权」**，没有才回退到读文字层。
- **🔗 相关文献四档**：Ctrl+R 把相关文件分成 **同丛书 / 同专题（同目录）/ 同一本书的其他书 / 同一作者的其他著作**。
- **❞ 注释一键插入（脚注）**：把选中引文（或剪贴板）+ 自动出处做成 **RTF 真脚注**，**粘到 Word 里即成脚注**（正文 + 脚注引用标记）。
- **⌛ 历史纪年换算**：识别引文中的**民国 / 年号 / 干支**纪年并在其后加【=公元年】（同时换算多个不同纪年）；**干支**列出 **1700–2000 年**全部对应年份。规则：**民国元年–民国38年不换算，民国39年及以后才自动换算**（如 民国四十年 = 1951 年）。并新增**随时可开的「历史纪年换算」小工具**（年号/民国/干支 ⇄ 公元互查）。**复制 PDF / TXT / 其它文件里的文字时**（含「复制本页文字」、鼠标拖选后右键复制）**自动在文末附上纪年换算**。

### 👤 人名别名归一（batch13）

近代人物常有多个 字 / 号 / 笔名 / 化名。搜「**吴佩孚**」会问你是否一并搜「子玉、吴玉帅、玉帅、孚威将军、孚威」；搜「**孙中山**」自动关联「孙文、逸仙、中山樵」。

- **内置一张可扩展的别名表**（含近代与古代人物，**随程序发布**，在 `config\person_alias.csv`，已达 **约 9.9 万人 / 15.7 万条**字号·笔名·化名）；检索到人物名时按设置处理：**询问我（默认）/ 自动并入 / 关闭**。命中的别名会一并进入结果，并在文件名里**多关键词黄底高亮**。
- **👤 人名别名**对话框（`Ctrl+Shift+A`）：查看/新增/删除、**导入/导出 CSV**、**从 CBDB 导入…**、按人名或字号反查。自己增补的写在本地 `person_alias.csv`（与设置同目录，不覆盖随包那份）。
- **数据来源**：内置精简表 + **CBDB（中国历代人物传记资料库）** 导出并入；也可继续导入你本地的 CBDB 官方导出目录（含 `ALTNAME_DATA.xlsx` / `BIOG_MAIN.xlsx`）——命令行 `py -3 开发\工具_CBDB导入别名表.py "<CBDB导出目录>"`（需 openpyxl）。同类数据源还有 Wikidata（别名，CC0）、中研院人名权威档、CN-DBpedia、维基/百科条目等。
- **致谢/许可**：别名数据含 **CBDB（Harvard/北大/中研院，学术免费、需引用）** 的衍生内容，请保留此出处。

## ⌨️ 快捷键

| 快捷键 | 作用 |
|---|---|
| `F11` | 全屏（自动隐藏工具栏与按钮行，再按恢复） |
| `PgUp` / `PgDn` | PDF 上一页 / 下一页（跳页） |
| `↑` / `↓` | PDF 平滑小步滚动（滚轮同理） |
| `Ctrl+Home` / `Ctrl+End` | PDF 首页 / 末页 |
| `Ctrl+F` | 文内查找（回车查找；`Esc` 关闭查找条） |
| `Ctrl+滚轮` | PDF 缩放（配合「缩放」下拉：适应宽度 / 适应页面 / 100%） |
| `Ctrl+T` | 目录（导航面板「目录」页签；PDF / EPUB 大纲，没大纲就列页码；**单击一项即跳页**） |
| `Ctrl+E` | 用 PDF 引擎打开当前项（支持 EPUB，也可直接开 PDF） |
| `Ctrl+B` | 记住当前位置（同一文件下次打开自动跳回） |
| `Ctrl+H` | 阅读历史（双击重开） |
| `Ctrl+K` | 搜索历史 / 已保存的搜索（双击重搜，可删除） |
| `Ctrl+D` | 保存当前搜索关键词 |
| `Ctrl+Shift+H` | 阅读统计 |
| `Ctrl+M` | Markdown 渲染 ⇄ 源码 切换 |

| `Ctrl+R` | 相关文件（同丛书 / 同作者 / 相邻书架） |
| `Ctrl+Shift+T` | 缩略图（导航面板「缩略图」页签，PDF / EPUB） |

按钮：

- **⤒ 版权页**：跳到当前这本书的版权页（当前项是 txt 时自动找同书 PDF）
- **↗ 用外部程序打开**：用系统默认程序打开当前文件（**只有点它才会调用外部程序**）
- **🗗 独立窗口**：把阅读器拆成独立窗口 / 收回主窗口
- **🔎 跨文件全文检索（在左侧列表上方）**：对当前搜索结果做跨文件全文检索（独立进程），不卡界面
- **🕘 检索历史**：调阅历次跨文件全文检索结果（自动保存）

- **v0.3.12**（2026-10-01）：**双页：够宽就并排；右边那页的出处也不再记错**
  - **① 能不能并排只看宽度**。以前「适应页面」模式下缩放取 `min(宽比, 高比)`，窗口一矮就把缩放压小，于是"并排后每页宽度不足"被判成单页 —— 明明左右铺得开，却退回单页。现在判据只看横向：**只要两页各能占到 400px 宽就排两列**，高度矮不过是滚动条长一点，不能被顶回去。

- **v0.3.8**（2026-10-01）：**「所有关键词」不再是摆设（一直 0/0 的修好了）**
  - **根因：两把尺子不一样**。后台扫词（导航条）用的是「原词 + 繁简变体 + 抹掉空白再连起来」；而查找栏那条合并序列却只做纯字面 `t.find(kw)`。书是繁体、关键词是简体时前者说"本书命中 3 处"，后者一处也找不到 —— 于是永远停在「第 0 / 0 处」。现在查找统一改用和扫词同一套口径（`_text_hit_spans`）。顺带的好处：**Ctrl+F 手打简体词**在繁体书里也能直接找到。
  - **跨行连起来的词也算命中**：竖排 / 分栏 OCR 会把一个词用换行切开（抽出来是 `'遜\n志\n堂'`），以前任何多字词都被硬生生切断，现在抹掉空白再连起来找。
  - **序号 0 也算出来了**：标签里有一句 `int(idx or -1)`，下标 0 被 `or` 当成没值吞掉 —— 就算有 4 处、正停在第 1 处，也写成"第 0 / 4 处"。
  - **页面黄框跟着繁体走**：高亮词列表现在会展开繁简变体，否则页面上写着「遜志堂雜鈔」、拿简体去 `search_for` 是画不出黄框的（位置算对了、页面上没反应，比 0/0 更纳闷）。
  - 命中的**真实跨度**记进了每条结果，跨行拼起来的词在 TXT 里选区才能框对。

- **v0.3.7**（2026-10-01）：**开 PDF 快了，命中词也不再等半天**
  - **开大书前先顺序预读一遍**（≥8 MB 的书）：PDF 解析是满文件随机跳转，冷读一本 120 MB 的书实测 11 秒，而顺序读一遍只要两三秒。先把整段文件拽进系统缓存，后面 fitz 的访问全部命中内存 —— **"第一个 PDF 特别慢"**主要靠这条解决。设环境变量 `CV_NOPREFETCH=1` 可关掉。
  - **页尺寸不再死等全本**：抽样（32 页）一致就先按它搭首屏；真遇上尺寸千奇百怪的书，扫到 1.2 秒也先交首屏（拿出现最多的尺寸铺满），剩下的后台扫完再纠正一次。以前碰到尺寸不齐的书只能干等整本扫完。
  - **命中词导航条立刻长出来**：`--words` 扫词改成**边扫边报**，每扫够 64 页就把目前的命中发一次 —— 那本 120 MB 的书实测第一批命中 0.4 秒就出来了（以前要等整本扫完 1.4 秒），后面陆续补齐。
  - **一本书的正文只抽一次**：抽过的文字层进缓存（最多 3 本，书改了自动失效），扫词 / 文内查找 / 命中词导航都复用，不再为同一本书开第二份 Document 重解析一遍。
  - **扫描版（没文字层）立刻收工**：前 24 页一个字都没有就判定是纯图 PDF，直接提示"多半是扫描版"，不再白等一整本。
  - **启动时悄悄预热引擎**：PyMuPDF / OpenCC 第一次 import 要把几十 MB 的 DLL 和词典拉进内存，以前算在"打开第一本书"头上；现在趁开完窗口的空闲在后台做掉。
